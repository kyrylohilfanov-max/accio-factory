# Контент-завод Accio — лендинг

Статический лендинг «Контент-завод Accio» для брендов и бизнеса: конструктор из 47 модулей, калькулятор объёма, тарифы, FAQ и форма заявки.

Без сборки и зависимостей: три файла, открываются в любом браузере.

```
index.html   — разметка
style.css    — стили (светлая тема, фиолетово-циановый акцент, CSS-3D на первом экране)
app.js       — конструктор, калькулятор, тарифы, форма
```

## Запуск

Откройте `index.html` в браузере — или включите GitHub Pages (Settings → Pages → Branch: `main`, folder `/`).

## Что настроить перед публикацией

**Цены** — в `app.js`, блок `CONFIG`:

```js
mgmtFee: 0,        // управление заводом, ₽/мес (0 = «Рассчитаем по брифу»)
creatorRate: 0,    // оплата одного креатора, ₽/мес
```

Когда оба значения больше нуля, калькулятор начинает показывать «от N ₽/мес» по формуле `управление + креаторы × ставка`.

**Тарифы** — массив `TARIFFS` в `app.js`: сейчас вместо цен стоит «Цена — по брифу».

**Заявка и корзина** — бэкенда нет и не нужно. Всё выбранное (модули, тариф, расчёт) падает в корзину, кнопка «Отправить в Telegram» открывает чат `t.me/<telegramUser>` с готовым текстом заявки — клиенту остаётся нажать «Отправить», а вы сразу видите его Telegram. Куда уходят заявки — `CONFIG.telegramUser` в `app.js`. Запасной вариант — «Скопировать заявку текстом».

**Услуги «Чаще всего берут отдельно»** — массив `POPULAR` в `app.js` (id модуля из `GROUPS`, текст, какие модули добавить вместе с ним).

**Контакты** — Telegram-аккаунт для заявок: `CONFIG.telegramUser` в `app.js`.

## Чего на странице нет

- Фото реальных креаторов и 3D-рендеров — объём на первом экране и в блоке «Инфраструктура остаётся у вас» сделан на CSS.
- Кейсов с цифрами — блок можно добавить, когда будут реальные данные.
