# Контент-завод Accio — лендинг

Статический лендинг «Контент-завод Accio» для брендов и бизнеса: конструктор из 47 модулей, калькулятор объёма, тарифы, FAQ и форма заявки.

Без сборки и зависимостей: три файла, открываются в любом браузере.

```
index.html   — разметка
style.css    — стили (светлая тема, фиолетово-циановый акцент, CSS-3D на первом экране)
app.js       — конструктор, калькулятор, тарифы, форма
```

## Запуск

Откройте `index.html` в браузере — или включите GitHub Pages (Settings → Pages → Branch: `main`, folder `/`).

## Что настроить перед публикацией

**Цены** — в `app.js`, блок `CONFIG`:

```js
mgmtFee: 0,        // управление заводом, ₽/мес (0 = «Рассчитаем по брифу»)
creatorRate: 0,    // оплата одного креатора, ₽/мес
```

Когда оба значения больше нуля, калькулятор начинает показывать «от N ₽/мес» по формуле `управление + креаторы × ставка`.

**Тарифы** — массив `TARIFFS` в `app.js`: сейчас цены стоят как `от [цена] ₽/мес`.

**Форма заявки** — бэкенд не подключён. Сейчас при отправке конфигурация копируется в буфер обмена и показывается ссылка на Telegram. Чтобы заявки приходили автоматически, замените обработчик `submit` в `app.js` на отправку в ваш бот / таблицу / CRM — текст заявки собирает функция `composeLead(form)`.

**Контакты** — ссылка на Telegram в `CONFIG.telegram` и в `index.html` (`@accio_pro_bot`).
